CHARUSAT Student Hub - Relational Database ER Model (studenthub_db)
users
• id (PK, INT)
• username (VARCHAR, UQ)
• email (VARCHAR, UQ)
• password_hash (VARCHAR)
• role (ENUM)
• is_active (TINYINT)
• remember_token_hash (VARCHAR)
• created_at (TIMESTAMP)
students
• id (PK, INT)
• user_id (FK → users.id)
• enrollment_no (VARCHAR, UQ)
• full_name (VARCHAR)
• email (VARCHAR, UQ)
• mobile (VARCHAR)
• course (VARCHAR)
• year (VARCHAR)
• gender (VARCHAR)
events
• id (PK, INT)
• title (VARCHAR)
• description (TEXT)
• event_date (DATE)
• venue (VARCHAR)
• category (VARCHAR)
• poster_path (VARCHAR)
• created_by (FK → users.id)
audit_logs
• id (PK, INT)
• user_id (FK → users.id)
• action_name (VARCHAR)
• entity_type (VARCHAR)
• entity_id (INT)
• details (TEXT)
• created_at (TIMESTAMP)
registrations
• id (PK, INT)
• student_id (FK → students.id)
• event_id (FK → events.id)
• registered_at (TIMESTAMP)
• status (ENUM)
• CONSTRAINT: UNIQUE(student, event)
